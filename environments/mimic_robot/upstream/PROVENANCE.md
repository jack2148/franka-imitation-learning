# Vendored Mimic environment source

Environment-only files were copied from
`https://github.com/tejasnaladala/mimic.git` at commit
`982d495ca77f3dbc53a8f8f267c6f623bdf8e5b8` (MIT license).

The upstream `pick-place` task and Panda assets are retained as the vanilla
baseline. `pick_place_fr3.py`, `tabletop_pick_place_fr3.xml`, the FR3 model,
and `adapter.py` are local integration additions.
